# Estate Car Theft Detection System

An intelligent vehicle security and monitoring platform for gated residential estates.

## Overview

The system integrates computer vision, automatic number plate recognition (ANPR), real-time event streaming and database-driven verification to monitor vehicle entry and exit activities.

## Core Features

- Resident and vehicle registration
- Automatic number plate recognition
- Visitor registration and authorization
- Vehicle entry and exit verification
- Suspicious movement detection
- Real-time security alerts
- CCTV evidence management
- Security monitoring dashboard

## Architecture

- Backend: Django REST Framework
- Verification: FastAPI
- Frontend: Next.js and TypeScript
- Database: PostgreSQL
- Messaging: Apache Kafka
- Cache: Redis
- Object Storage: MinIO
- Computer Vision: YOLO, OpenCV and PaddleOCR
- Infrastructure: Docker Compose
